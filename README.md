# MALLOW / TACTICS (말랑 작전실)

행동 패턴을 짜서 보스를 공략하는 2D 턴제 전투 프로토타입입니다. 빌드 과정 없이 HTML 파일 하나로 돌아갑니다.

## 파일

- `mallow-tactics.html`: 원본. Claude 아티팩트로 올리는 버전이라 `<!doctype>`/`<head>` 뼈대가 없습니다. 수정은 이 파일에서 합니다.
- `index.html`: `mallow-tactics.html`에 문서 뼈대만 붙인 단독 실행용 파일. 브라우저로 바로 열 수 있습니다. 원본을 고친 뒤에는 이 파일도 같은 내용으로 다시 만들어 주세요.

## 구조 (mallow-tactics.html)

- `/*ENGINE*/ … /*END ENGINE*/`: 전투 규칙. 화면과 분리된 순수 로직이라 `simulate(cfg)`로 밸런스를 시험할 수 있습니다.
  - 행동 게이지: 각 유닛이 속도만큼 게이지를 채우고 100%에 먼저 닿은 유닛이 행동 (`nextActor`)
  - SP, 행동 패턴(조건 → 스킬), 보스 패턴과 분기, 변이 효과, BREAK
  - 전열/후열: 보스는 다음 공격이 노릴 줄을 미리 정해 보여 줍니다(65% 전열). 전열은 주는 피해 +20%, 후열은 받는 피해 -20%(1스테이지 튜토리얼에서는 「피해를 더 줘요 / 받는 피해가 감소해요」로 안내). 가드·도발 중인 아군은 줄 공격을 혼자 대신 맞습니다 (`aimOf`)
  - 가드·버티기·도발은 보스가 실제로 공격(공격·광역·돌진)할 때까지 유지됩니다
  - 집중 공격: 자동 전투 중 적을 누르면 `battle.focus`가 정해져 모든 공격이 그 적부터 갑니다
  - 수동 선택은 SP만 있으면 무엇이든 쓸 수 있습니다(HP가 가득 차도 회복 가능). 자동 패턴은 `valid`로 헛도는 스킬을 건너뜁니다
- 그 아래: 화면 렌더링, 연출(투사체, 컷신), 튜토리얼 스포트라이트(`coach`, 프로필마다 한 번씩), 성장(단계, 레벨, 장비, 반복 전투), 저장(localStorage)

## 진행 흐름

- 처음엔 캐릭터 1명. 닉네임과 모습(성별 · 헤어 · 피부)을 정해서 시작합니다. 모습은 스프라이트의 머리·피부 픽셀을 캔버스로 다시 칠해 만듭니다 (`recolor`)
- 닉네임은 직접 입력해야 만들 수 있습니다
- 처음부터 동료 영입까지는 안내 모드: 다음에 누를 곳만 밝고 나머지는 어둡고 눌리지 않습니다 (`guideSel`)
- 1~2스테이지는 혼자 싸웁니다. 1스테이지는 주먹질 · 응급 붕대만(주먹질 → 다친 뒤 붕대 순서로 한 번씩 직접 써 봄), 2스테이지(보스 HP 200)는 첫 광역 공격 예고 때 버티기가 열려 한 번 쓰고, 그 뒤 HP가 70% 아래면 붕대를 한 번 직접 씁니다
- 2스테이지 출발 전에 모험 지도를 안내합니다
- 2스테이지를 깨면(`RECRUIT_STAGE`) 캐릭터 탭이 열리고 동료를 데려옵니다(파티가 4명이 될 때까지 무료, 이후 🪙200). 3스테이지 첫 도전은 4명이 출전해야 시작됩니다
- 동료 영입 안내: 화면을 밝게 둔 채 설명 → 데려오기 버튼만 밝힘 → 첫 동료 생성 창에서 성별 · 헤어 · 피부 · 닉네임을 하나씩 안내. 4명이 되면 드래그 배치를 자동으로 한 번 시연(`dragDemo`)
- 3스테이지 전투 전: 보스 · 졸개 · 아군을 누르면 확인할 수 있다고 안내. 4 · 5스테이지는 출발 · 전투 시작 버튼을 짚어 줍니다
- 작전 · 가방 · 보스 탭은 7스테이지를 깨면(`TABS_STAGE`) 열리고, 각 탭은 처음 열 때 안내가 나옵니다. 지도에서 7스테이지부터는 🎁(장비 나옴) 표시, 7스테이지 출발 전에 안내
- 4스테이지 첫 응시는 자동 전투 중에도 직접 🪨 돌팔매를 눌러 끊습니다
- 장비는 7스테이지부터 나옵니다. 처음 4명 이후 🪙로 데려온 동료는 Lv1부터 시작합니다
- 모든 전투는 멈춘 채로 열립니다. 적·아군을 눌러 상태를 보고 「▶ 전투 시작」을 누르면 시작합니다
- 지면 보상이 적습니다(EXP는 승리의 약 10%). 처음 전직 가능 알림이 뜨면 바로 한 명을 전직하는 안내 모드로 이어집니다(7스테이지 패배 시에도, 아직 안 했다면)
- 캐릭터 탭: 출전 파티는 전열/후열 2칸씩. 캐릭터를 끌어다 놓아 이동(파티끼리는 맞바꿈, 대기 파티에서 끌어오면 교체, 대기 파티 칸에 놓으면 출전 해제). 누르면 상세 정보
- 누를 수 없는 버튼을 누르면 이유가 말풍선으로 뜹니다(`setWhy`)
- 전투 로그 창은 열어 둔 동안 실시간으로 갱신됩니다
- 1~2스테이지: 수동 튜토리얼. 스킬을 누르면 설명 창이 뜨고, 설명 창을 한 번 더 누르면 사용(공격은 체력이 가장 낮은 졸개부터, 적을 직접 눌러 고를 수도 있음)
- 2스테이지를 깨면 자동 전투가 열립니다. 모드 버튼은 따로 없고, 자동 전투를 멈추면 바로 직접 조작으로 바뀝니다
- 4스테이지(바위 골렘): 응시 → BREAK, 껍질
- 5스테이지 첫 클리어 후 파티 전원이 Lv5가 되어 전직할 수 있습니다 (검사 · 마법사 · 치유사 · 궁수). 꼭 모두 전직할 필요는 없습니다
- 6스테이지부터(`BG_STAGE`): 전직 · 스킬 · 배치를 잘 골라야 이기는 난이도(작전 탭은 7 클리어 후, 장비는 7부터)이고, 자동 전투 중 다른 탭을 봐도 전투가 계속됩니다. 그 전에는 다른 탭으로 가면 멈췄다가 돌아오면 이어집니다
- 스킬: SP + 쿨타임(자기 차례 기준). 색으로 종류 구분, 스킬바도 이 순서: 🟥 공격 · 🟩 회복 · 🟦 방어 · 🟨 특수. 버티기는 SP +30도 줍니다
- 시간 제한 없음. 시뮬레이터만 200턴에서 끊습니다(회복형 졸개와의 무한 교착 방지)
- ×2 배속은 6스테이지부터, 한 번 깬 스테이지에서만
- 전투 시작 때 행동 게이지는 속도에 비례해 조금 차 있습니다
- 재화는 골드 하나입니다 (스킬 배우기도 골드)

## 현재 밸런스 기준 (기본 패턴 자동전투, 400판 시뮬레이션)

- 1스테이지 혼자 Lv1: 100%
- 2스테이지 혼자 Lv2(보스 HP 200): 어떤 패턴이든 100%, 남은 HP 37~55%. 붕대 한 번은 튜토리얼로 보장
- 3스테이지 4명 Lv3: 100% / 4스테이지 Lv4·Lv3 파티: 100%, 남은 HP 약 37%
- 5스테이지(보스 HP 650 · 휘두르기 80 · 돌진 110, 돌진이 안 오는 줄은 버티기 대신 공격) 4명 Lv4 방랑자: 100%, 쓰러짐 0, 남은 HP 약 62% / Lv3만이어도 100%
- 6스테이지: 막 전직한 Lv5 약 40% / 작전 · 성장 후 100%
- 7스테이지(심연의 문): 직업 첫 스킬만으로는 Lv8에도 약 33% / 직업 스킬 2개 + 돌팔매 · 붕대를 장착하면 Lv6부터 100% (작전 탭 없이 기본 패턴)

- 별 수집: 스테이지마다 별 3개(격파 · 전원 생존 · 정해진 턴 안에 격파)와 별에 따른 추가 보상. 지금은 뺐습니다
