# MALLOW / TACTICS (말랑 작전실)

행동 패턴을 짜서 보스를 공략하는 2D 턴제 전투 프로토타입입니다. 빌드 과정 없이 HTML 파일 하나로 돌아갑니다.

## 파일

- `mallow-tactics.html`: 원본. Claude 아티팩트로 올리는 버전이라 `<!doctype>`/`<head>` 뼈대가 없습니다. 수정은 이 파일에서 합니다.
- `index.html`: `mallow-tactics.html`에 문서 뼈대만 붙인 단독 실행용 파일. 브라우저로 바로 열 수 있습니다. 원본을 고친 뒤에는 이 파일도 같은 내용으로 다시 만들어 주세요.

## 구조 (mallow-tactics.html)

- `/*ENGINE*/ … /*END ENGINE*/`: 전투 규칙. 화면과 분리된 순수 로직이라 `simulate(cfg)`로 밸런스를 시험할 수 있습니다.
  - 행동 게이지: 각 유닛이 속도만큼 게이지를 채우고 100%에 먼저 닿은 유닛이 행동 (`nextActor`)
  - SP, 행동 패턴(조건 → 스킬), 보스 패턴과 분기, 변이 효과, BREAK
  - 전열/후열: 보스는 다음 공격이 노릴 줄을 미리 정해 보여 줍니다(65% 전열). 전열은 주는 피해 +20%, 후열은 받는 피해 -20%. 가드·도발 중인 아군은 줄 공격을 혼자 대신 맞습니다 (`aimOf`)
  - 가드·버티기·도발은 보스가 실제로 공격(공격·광역·돌진)할 때까지 유지됩니다
  - 집중 공격: 자동 전투 중 적을 누르면 `battle.focus`가 정해져 모든 공격이 그 적부터 갑니다
  - 수동 선택은 SP만 있으면 무엇이든 쓸 수 있습니다(HP가 가득 차도 회복 가능). 자동 패턴은 `valid`로 헛도는 스킬을 건너뜁니다
- 그 아래: 화면 렌더링, 연출(투사체, 컷신), 튜토리얼 스포트라이트(`coach`, 프로필마다 한 번씩), 성장(단계, 레벨, 장비, 반복 전투), 저장(localStorage)

## 진행 흐름

- 처음엔 캐릭터 1명. 닉네임과 모습(성별 · 헤어 · 피부)을 정해서 시작합니다. 모습은 스프라이트의 머리·피부 픽셀을 캔버스로 다시 칠해 만듭니다 (`recolor`)
- 닉네임은 직접 입력해야 만들 수 있습니다
- 동료는 골드로 데려옵니다(🪙60 → 100 → 140, 이후 200). 모험 지도의 「＋ 동료」나 캐릭터 탭에서. 한 스테이지를 깨면 다음 동료값이 모이도록 보상을 맞췄습니다
- 4스테이지를 깰 때까지(`TUTORIAL_END`)는 전투 탭만 쓸 수 있고, 열린 뒤 각 탭은 처음 열 때 안내가 나옵니다
- 캐릭터 탭: 출전 파티는 전열/후열 2칸씩. 캐릭터를 누르고 다른 칸을 누르면 이동(파티끼리는 맞바꿈, 대기 파티에서 데려오면 교체)
- 1~2스테이지: 수동 튜토리얼. 스킬을 누르면 설명 창이 뜨고, 공격 스킬은 적을 눌러 쓰고 나머지는 ✔ 사용
- 2스테이지를 깨면 자동 전투가 열립니다. 모드 버튼은 따로 없고, 자동 전투를 멈추면 바로 직접 조작으로 바뀝니다
- 4스테이지(바위 골렘): 응시 → BREAK, 껍질. 첫 클리어 후 파티가 Lv5가 되어 전직할 수 있습니다 (검사 · 마법사 · 치유사 · 궁수)
- 5스테이지부터(`BG_STAGE`): 패턴 · 장비 · 스킬을 잘 짜야 이기는 난이도이고, 자동 전투 중 다른 탭을 봐도 전투가 계속됩니다. 그 전에는 다른 탭으로 가면 멈췄다가 돌아오면 이어집니다
- 스킬: SP + 쿨타임(자기 차례 기준). 색으로 종류 구분: 🟥 공격 · 🟦 방어 · 🟩 회복 · 🟨 특수
- 시간 제한 없음. 시뮬레이터만 200턴에서 끊습니다(회복형 졸개와의 무한 교착 방지)
- ×2 배속은 6스테이지부터, 한 번 깬 스테이지에서만
- 전투 시작 때 행동 게이지는 속도에 비례해 조금 차 있습니다
- 재화는 골드 하나입니다 (스킬 배우기도 골드)

## 현재 밸런스 기준 (기본 패턴 자동전투, 400판 시뮬레이션)

- 1스테이지 1명 Lv1, 2스테이지 2명 Lv2(혼자도 가능, 약 12턴), 3스테이지 3명 Lv3: 승률 100%
- 4스테이지 4명 Lv4: 100%, 남은 HP 약 37% (3명이면 약 50%)
- 5스테이지, 막 전직한 Lv5 파티: 약 87% / 레벨 · 스킬 · 장비를 키우면 100%
- 6스테이지: 기본 약 55% / 성장 후 100%
- 7스테이지(심연의 문): 막 전직한 파티는 거의 못 이김 / Lv7 + 스킬이면 100%

## 나중에 넣을 아이디어

- 2차 커스터마이징: 얼굴, 장비 외형 등 (지금은 성별 · 헤어 · 피부만)
- 별 수집: 스테이지마다 별 3개(격파 · 전원 생존 · 정해진 턴 안에 격파)와 별에 따른 추가 보상. 지금은 뺐습니다
- 2차 전직: 검사 → 창술사 · 마검사, 그 밖에 음유시인 · 성기사 · 도적 등. 이 직업들의 스프라이트는 `SPRITES`에 남아 있습니다
