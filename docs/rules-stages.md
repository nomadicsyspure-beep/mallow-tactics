# 스테이지 · 밸런스

> 확정된 결정. 결정이 바뀌면 이 파일을 고친다. 코드 위치는 `docs/CODEMAP.md`.

새 보스·졸개·스테이지 수치는 `src/engine/data.js`의 `STAGES`. 고친 뒤 `node tools/sim.js`로 확인한다.

## 스테이지 흐름
- 1: 수동 튜토리얼, 스킬은 주먹질 · 응급 붕대만(`tutSkills`)
- 2: 수동. 졸개 HP 30, 보스 HP 200 · 광역 110. HP 200이면 수치로 치유 필수는 안 됨 → 튜토리얼로 붕대 한 번 보장. 첫 광역 예고 때 🧱 버티기가 열리고(`unlockBrace`, `prof.braceOpen`) 한 번 직접 써 봄. 클리어 시 자동 전투 + 캐릭터 탭 열림
- 2 클리어(`RECRUIT_STAGE`) → 캐릭터 탭에서 동료 영입(무료). 3스테이지 첫 도전은 출전 4명이어야 시작(`needRecruit`, 시작 버튼 「👥 동료 4명 필요」). 4명이 되면 데려오기 버튼은 🪙200(골드 부족으로 비활성), 드래그 배치 · 전열/후열 설명 → 자동으로 전투 탭 → 「3스테이지로 출발!」을 누르면 안내 모드 끝
- 3~5: 기본 패턴 자동으로도 깨짐. 3은 아주 쉬움(보스 200, 새끼 늑대 120). 4(바위 골렘)에서 응시·BREAK·껍질, 첫 응시는 🪨를 직접 눌러 끊음. 5는 보스 HP 650 · 휘두르기 80 · 돌진 110 (전열 안 쓰러짐)
- 경험치 `expNeed=50×레벨`: 1~5 첫 클리어로 동료까지 전원 Lv5 → 6 시작 전에 전직 가능(필수 아님, 여러 직업 키워 보기 추천 안내)
- 작전·가방·보스 탭은 7 클리어(`TABS_STAGE`) 후 열림(`tabOpen(id)`), 각 탭 첫 진입 시 안내
- 6(`BG_STAGE`)부터: 전직·스킬·배치를 잘 골라야 이기는 난이도(6~7은 작전 탭 없이 기본 패턴 + 직업 스킬 장착으로 깨짐), 자동 전투 중 다른 탭으로 가도 계속 진행(그 전엔 멈췄다가 복귀 시 재개)

## 밸런스 기준 (기본 패턴, 400판 시뮬레이션)
- 2(혼자 Lv2, 보스 200): 모든 패턴 100%(HP 37~55%) / 3(4명 Lv3): 100% / 4(Lv4·Lv3 파티, 보스 HP 900 · 공격 110 · 광역 130): 100%, HP 약 68%, 평균 4.5턴, 쓰러짐 0 / 5(4명 Lv4 방랑자): 100%, HP 약 62%, 쓰러짐 0, Lv3만이어도 100% / 7: 직업 첫 스킬만이면 Lv8도 약 33%, 직업 스킬 2개 장착 Lv6부터 100% / 6(보스 HP 1250 · 공격 125 · 광역 200, 막 전직 Lv5): 100%, HP 약 43%
- 보스 HP는 예전의 절반 이하 유지, 난이도는 공격력·속도로 조절
