# 전투 규칙

> 확정된 결정. 결정이 바뀌면 이 파일을 고친다. 코드 위치는 `docs/CODEMAP.md`.

- 스킬: SP + 쿨타임(자기 차례 기준). 색 = 종류, 안내·스킬바 순서: 🟥공격 🟩회복 🟦방어 🟨특수(`sortSkills`). 누르면 설명 창 → 설명 창을 한 번 더 누르면 사용(공격은 체력이 가장 낮은 졸개부터, `autoTgt`), 공격은 적을 직접 눌러 고를 수도 있음. 「한 번 더 누르면 사용」 같은 안내는 설명 창 위에 띄움(`.sp-float`), 설명 창 안은 깔끔하게
- 방랑자 스킬: 주먹질 · 응급 붕대 · 버티기(받는 피해 -50%, SP도 30을 채워줘요) · 돌팔매. 응원은 삭제
- 아군 HP 바는 연한 빨강
- 수동 선택은 SP·쿨타임만 맞으면 무엇이든 가능(HP 가득해도 회복 가능). 자동 패턴만 헛도는 스킬을 건너뜀
- 버티기·가드·도발: 보스가 실제로 공격할 때까지 유지
- 자동/수동: 버튼 하나. 자동을 멈추면 바로 직접 조작. 모든 전투는 수동으로 시작(3스테이지부터 원하면 자동, 3의 첫 수동 차례에 자동 버튼 안내). 자동 중 스킬을 누르면 설명만 보이고, 수동이면 차례인 캐릭터의 스킬 탭이 자동으로 열림. 자동 전환 안내는 작전 탭이 열리기 전엔 「기본 설정된 패턴대로」
- 변이 시스템: 꺼 둠(지도·전투·도감에서 삭제, 엔진의 `MUTS`만 남겨 둠). 심연 스테이지 보상 보너스는 유지
- 스킬 장착: 캐릭터당 8칸(`EQUIP_SLOTS`). 스킬바는 5개가 넘으면 아이콘을 줄여 한 줄에 모두 표시
- 결과창 「다시」는 7스테이지까지는 졌을 때만
- 적·아군 정보 말풍선은 다시 터치할 때까지 유지(`whyTip(b,true)`), 3스테이지 확인 안내는 말풍선을 닫으면 다음으로
- 집중 공격: 자동 전투 중 적을 누르면 그 적부터 공격. 수동 전투에서는 집중 공격이 없고, 적을 누르면 정보가 뜸(공격 스킬로 타겟 고를 때만 그 적을 공격)
- 클리어 조건: 보스와 졸개를 모두 쓰러뜨려야 승리. 보스만 먼저 쓰러지면 「보스 격파!」 후 남은 졸개를 잡음(남은 졸개는 보스를 돕지 못하고 아군을 때림)
- 6스테이지(`BG_STAGE`) 전에는 전투가 시작되면 끝날 때까지 다른 탭으로 못 감(누르면 「전투가 끝나면 갈 수 있어요」)
- 시간 제한 없음(패배 = 전멸). 시뮬레이터만 200턴 교착 컷
- 배속: ×2만, 6스테이지 이상 + 한 번 깬 맵에서만
- 전투 로그 창을 열어 두면 실시간으로 갱신(맨 아래를 보고 있으면 자동 스크롤)
- 적 턴에 열어 둔 스킬 설명 창은 내 차례가 와도 닫히지 않고 바로 쓸 수 있게 이어짐
- 한 번 재생하는 흔들림 클래스(quake 등)는 끝나면 지움(`ONE_SHOT`) → 전투 탭으로 돌아올 때 화면이 흔들리지 않음
- 자동 패턴: 돌진이 노리지 않는 줄의 🧱는 건너뜀(후열은 공격)
- 모든 전투는 멈춘 상태로 시작(`preFight`): 적·아군을 눌러 상태 확인(`infoTip`), 스킬 설명 확인 후 「▶ 전투 시작」
- 반복 ×5 버튼은 삭제(`repeatRun`만 남겨 둠, 나중에 다시)
