# 튜토리얼 · 안내

> 확정된 결정. 결정이 바뀌면 이 파일을 고친다. 코드 위치는 `docs/CODEMAP.md`.

- 1스테이지 스킬 종류 안내는 점 없이 「🟥 공격  🟩 회복  🟦 방어  🟨 특수」. 3스테이지 일점사 안내는 자동 전투에서 보스 첫 턴 뒤. 7스테이지부터 붕대 안내(HP 낮음) 없음
- 안내 모드(`guideSel`/`drawGuide`): 첫 캐릭터 생성부터 동료 4명 영입 + 배치 설명까지(`prof.guideDone`)는 다음에 누를 곳만 밝고 나머지는 어둡고 눌리지 않음. 같은 층으로 정해진 튜토리얼 스킬(`forceSk`: 2스테이지 첫 광역 예고의 🧱, 4스테이지 첫 응시의 🪨)도 직접 누르게 함
- 전열/후열 문구: 1스테이지 전투 튜토리얼만 「상대에게 주는 피해가 증가해요 / 상대로부터 받는 피해가 감소해요」, 배치 튜토리얼·아군 정보·도감은 「주는 피해 +20% / 받는 피해 -20%」
- 팁 보강: 탭 버튼을 짚는 팁은 그 탭이 반짝임(`glow`), 화면 밖 대상은 자동 스크롤(`scrollToSee`), 누른 뒤 정보 말풍선을 읽을 시간(`hold`). 3스테이지 전 보스·졸개·아군을 실제로 눌러 정보 확인. 2스테이지 「가장 약한 졸개부터」 팁은 설명 창을 짚어 한 번 더 누르게 함
- 안내 모드에서도 어둡게 가린 곳이 없는 순간(적 차례 등)에는 ☰ 설정을 열 수 있음. 설정·로그 창이 열려 있는 동안은 안내 모드가 쉼
- 스포트라이트 팁은 한 곳씩 짚는다(적 → 체력바, 캐릭터 → HP바 → SP바 등). 누를 곳을 짚는 팁(`press`)은 빛나는 곳을 한 번 누르면 바로 눌러짐, 다른 곳은 반응 없음
- 안내 모드에선 밝은 곳만 눌림(어두운 곳은 일절 반응 없음). 결과창은 EXP 바가 다 찰 때까지(`SHOW_RESULT_MS`), 캐릭터 탭은 잠깐(`SHOW_CHARS_MS`) 보여 준 뒤 다음 버튼을 짚음. 튜토리얼 중엔 개별 스킬의 금색 깜빡임 없음
- 전직 안내: 처음 「전직할 수 있어요!」 알림이 뜨면(보통 5 클리어) 바로 한 명을 전직하는 안내 모드: 캐릭터 탭 → 캐릭터 고르기 → 전직하기 → 직업 선택(`prof.jobTut`/`jobTutDone`). 7스테이지(`JOB_TUT_STAGE`)에서 지고 Lv5 방랑자가 남아 있으면 한 번 더(`prof.jobRound=2`)
- 팁 종류: `coach(…,press,bright)` bright=어둡게 하지 않고 테두리만, `coachDo(kind,fn)` 팁 사이에 자동 시연(진행 중엔 탭 막힘). 창(모달) 위 팁은 창보다 위에 뜸
- 튜토리얼 직접 써 보기(`tutForce`): 1스테이지 👊 → 다친 뒤 🩹, 2스테이지 🧱(첫 광역 예고) → HP 70% 아래면 🩹, 4스테이지 🪨(첫 응시)
- 동료 영입 안내: 밝은 화면 설명 → 버튼만 밝힘 → 첫 동료 생성 창에서 성별·헤어·피부·닉네임 하나씩 → 4명이면 드래그 시연(`dragDemo`) → 전열/후열 → 3스테이지 출발
- 지도 안내(`goTips`): 2 출발 전 모험 지도 설명, 4·5 출발 버튼, 7 출발 전 🎁 지역. 1~5스테이지는 「전투 시작」 버튼도 짚음(`fight`+스테이지)
